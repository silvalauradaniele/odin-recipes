# Odin Recipes

This is my first project from The Odin Project. The purpose is to practice my basic HTML skills by building a simple recipes webpage.

## Features

* A main homepage
* Individual recipe pages linking to their original webpages
* Use of core HTML principles
* Image integration

## Technologies

* HTML5
* Git
* GitHub

## What I Learned

During this project, I learned the basics of Git, including how to create a repository, commit, and push changes, as well as how to use GitHub.
I also developed the skills to build a simple webpage featuring links, images, and subpages.

## How to view the project

1. Clone this repository:
   ```bash
   git clone git@github.com:silvalauradaniele/odin-recipes.git
   ```
2. Navigate to the project folder:
   ```bash
   cd odin-recipes
   ```
3. Open the `index.html` file in any web browser.
